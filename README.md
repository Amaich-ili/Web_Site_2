# Web_Site_2

## 🎯 Objectif

Deuxième projet d'entraînement en **HTML / CSS responsive**.  
Un site vitrine pour présenter des services, un portfolio et des tarifs.

## 🛠️ Technologies utilisées

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)

## 📱 Responsive

Le site s'adapte à toutes les tailles d'écran :
- **Mobile** : < 768px
- **Tablette** : 768px - 1024px
- **Desktop** : > 1024px

## ✨ Sections du site

- **En-tête** avec présentation
- **Services** proposés
- **Portfolio** (filtrage en CSS pur)
- **À propos** avec chiffres clés
- **Témoignages**
- **Tarifs** (4 offres)
- **Contact** (adresse et téléphone)
